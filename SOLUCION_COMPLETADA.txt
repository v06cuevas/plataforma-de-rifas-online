🚀 PASOS A SEGUIR (5 minutos):

PASO 1: CONFIGURAR SUPABASE (2 minutos)
   1. Abre https://app.supabase.com/
   2. Ve a SQL Editor
   3. Copia y ejecuta este SQL:

      ALTER PUBLICATION supabase_realtime ADD TABLE raffles;
      ALTER PUBLICATION supabase_realtime ADD TABLE tickets;
      ALTER PUBLICATION supabase_realtime ADD TABLE payment_reports;
      ALTER PUBLICATION supabase_realtime ADD TABLE draw_results;
      ALTER PUBLICATION supabase_realtime ADD TABLE support_conversations;
      ALTER PUBLICATION supabase_realtime ADD TABLE raffle_stats;

   4. Espera "Success" ✅


PASO 2: DESPLEGAR EN VERCEL (1 minuto)
   cd c:\Users\o\Desktop\plataforma-de-rifas-online

   git add .
   git commit -m "feat: Actualizaciones en tiempo real y sesión persistente"
   git push origin main

   Espera 2-3 minutos a que Vercel termine el despliegue ✅


PASO 3: PROBAR (2 minutos)
   1. Abre tu app en Vercel
   2. Inicia sesión y recarga la página
      → Sesión persiste ✅
   3. Abre en 2 pestañas: Admin + Cliente
   4. Admin: Crea una nueva rifa
      → Cliente ve cambio en < 1 seg ✅
   5. Abre DevTools (F12) → Console
      → Deberías ver logs de Realtime ✅
